## 📋 项目概述

基于 **StrDiffusion（IR-SDE）** 扩散框架 + **BrushNet** 特征注入，实现壁画/图像褪色区域的颜色复原与修复。

**核心思路**：双阶段处理
- **Stage 1**: 生成颜色先验图和置信度图（传统图像处理）
- **Stage 2**: 扩散模型引导修复（深度学习）

---

## ⭐ 双阶段核心流程

### Stage 1：颜色先验与置信度生成

**输入**：
- `original_degraded`: 原始褪色图像 [B, 3, H, W]，范围 [0, 1]
- `mask`: 修复区域掩码 [B, 1, H, W]，1=已知，0=缺失

**输出**：
- `color_prior`: 颜色先验图 [B, 3, H, W]，范围 [0, 1]
- `confidence`: 置信度图 [B, 1, H, W]，范围 [0, 1]
- `color_changed`: 颜色变换后的图像（作为 Stage 2 的训练目标）

**处理流程**：

```
original_degraded
       ↓
   ① 去噪预处理（双边滤波）
       ↓
   denoised_original
       ↓
   ② LUT 三线性插值 → lut_transformed + lut_confidence
       ↓
   ③ 双边滤波平滑（减少颜色割裂）
       ↓
   ④ 置信度加权混合
      effective_weight = lut_strength × lut_confidence
      result = denoised × (1 - weight) + lut × weight
       ↓
   ⑤ 根据 gt_mode 决定最终输出
      - full: 全图使用 LUT 结果
      - partial: 仅 mask=0 区域使用 LUT，mask=1 保持原色
       ↓
   color_changed (训练目标)
```

**关键配置参数** (`ir-sde-brushnet.yml`)：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `lut_path` | - | LUT 文件路径 (.npz) |
| `lut_strength` | 0.7 | LUT 强度 (0~1)，乘以置信度 |
| `lut_smooth_radius` | 5 | LUT 结果平滑半径 |
| `gt_mode` | partial | full/partial，决定 LUT 应用范围 |

---

### Stage 2：扩散模型修复（IR-SDE + BrushNet）

**目标**：让模型学习从噪声状态恢复到 `color_changed`（Stage 1 的输出）

#### 2.1 训练数据流

```
                    ┌─────────────────────────────────────┐
                    │          train.py 数据准备           │
```

#### 2.2 optimize_parameters() 核心逻辑

```python
# =============== 第一阶段处理（在模型内部）===============
with torch.no_grad():
    # 1. 对原始图像去噪
    denoised_original = self._denoise_image(self.original_degraded)
    
    # 2. 应用 LUT 变换
    lut_transformed, lut_confidence = self.lut_processor.apply_to_tensor(denoised_original)
    
    # 3. 平滑处理
    if self.lut_smooth_radius > 0:
        lut_transformed = self._guided_smooth(lut_transformed, guide=denoised_original)
    
    # 4. 置信度加权混合
    effective_weight = self.lut_strength * lut_confidence
    lut_transformed = denoised_original * (1 - weight) + lut_transformed * weight
    
    # 5. 根据 gt_mode 决定训练目标
    if gt_mode == 'full':
        training_target = lut_transformed
    else:  # partial
        training_target = denoised_original * mask + lut_transformed * (1 - mask)

# =============== 第二阶段 SDE 训练 ===============
sde.set_mu(self.condition)  # condition = Y_degraded * mask

# 计算最优反向步（目标）
yt_1_optimum = sde.reverse_optimum_step(self.state, training_target, timesteps)

# 准备 BrushNet 条件
brushnet_kwargs = {
    'color_prior': self.color_prior,
    'confidence': self.confidence,
    'mask': 1 - self.mask  # BrushNet 约定: 1=需要修复
}

# 网络预测噪声
noise, _ = sde.noise_fn(self.state, timesteps, S_optimum, **brushnet_kwargs)

# 计算模型输出
score = sde.get_score_from_noise(noise, timesteps)
yt_1_expectation = sde.reverse_sde_step_mean(self.state, score, timesteps)

# 损失计算
loss = MatchingLoss(yt_1_expectation, yt_1_optimum, self.mask)
# MatchingLoss: mask=1 区域权重 1，mask=0 区域权重 10
```

## 🔧 Mask 语义约定 (完整追踪)

**⚠️ 重要**：整个代码中 mask 语义在不同位置有所不同，必须理解转换链路！

### 完整 Mask 流程追踪

```
┌─────────────────────────────────────────────────────────────────────┐
│ 1. 数据集层 (mural_inpainting_dataset.py)                           │
├─────────────────────────────────────────────────────────────────────┤
│ _generate_dynamic_mask():                                           │
│   mask = np.zeros(...)                                              │
│   mask[y1:y2, x1:x2] = 255  ← 255 表示需要修复的区域                  │
│                                                                     │
│ __getitem__():                                                      │
│   mask_tensor = mask / 255.0  ← tensor中 1.0=需要修复, 0.0=已知      │
│   return {'mask': mask_tensor, ...}                                 │
└─────────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────────┐
│ 2. 训练脚本 (train.py)                                              │
├─────────────────────────────────────────────────────────────────────┤
│ mask = train_data["mask"]       ← 此时 1=需要修复, 0=已知            │
│                                                                     │
│ # 关键转换！SDE 需要相反的语义                                        │
│ if is_mural_mode:                                                   │
│     mask_for_sde = 1 - mask     ← 转换后: 1=已知, 0=需要修复         │
│                                                                     │
│ model.feed_data(..., mask_for_sde, ...)                             │
└─────────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────────┐
│ 3. 模型层 (denoising_model.py)                                      │
├─────────────────────────────────────────────────────────────────────┤
│ self.mask = mask_for_sde        ← 此时 1=已知, 0=需要修复            │
│                                                                     │
│ # partial 模式下的 GT 生成:                                          │
│ color_changed = denoised * self.mask + lut * (1 - self.mask)        │
│                 ↑已知区域保持原色    ↑缺失区域使用LUT                  │
│                                                                     │
│ # 损失计算:                                                          │
│ loss = lossu + 10 * lossm                                           │
│        ↑mask=1区域    ↑mask=0区域(权重更高)                          │
│                                                                     │
│ # BrushNet 需要再次取反!                                             │
│ brushnet_kwargs['mask'] = 1 - self.mask  ← BrushNet: 1=需要修复     │
└─────────────────────────────────────────────────────────────────────┘
```

### 各模块 Mask 语义速查表

| 位置 | 变量名 | 1 的含义 | 0 的含义 |
|------|--------|----------|----------|
| 数据集输出 | `mask` (tensor) | **缺失/需修复** | 已知 |
| train.py 转换后 | `mask_for_sde` | **已知** | 缺失/需修复 |
| model 内部 | `self.mask` | **已知** | 缺失/需修复 |
| BrushNet 输入 | `brushnet_kwargs['mask']` | **缺失/需修复** | 已知 |
| MatchingLoss | `mask` 参数 | 权重=1 | 权重=10 |

### 关键代码示例

```python
# train.py 第 372-375 行
if is_mural_mode:
    mask_for_sde = 1 - mask  # 数据集mask(1=缺失) → SDE mask(1=已知)
else:
    mask_for_sde = mask      # 旧数据集本身就是 1=已知

# denoising_model.py 第 347 行
brushnet_kwargs['mask'] = 1 - self.mask  # SDE mask(1=已知) → BrushNet(1=需修复)

# denoising_model.py 第 318 行 (partial模式)
color_changed = denoised_original * self.mask + lut_transformed * (1 - self.mask)
#               已知区域(mask=1)保持原色        缺失区域(mask=0)使用LUT
```

```python
denoised = denoise_image(img)

    color_prior = lut_result

noisy_state = sde.noise_state(img * mask)
```

## ✅ 可扩展点

1. **BrushNet 注入方式**：目前是直接相加，可改为 attention gating
2. **置信度利用**：目前只作为输入通道，可作为 loss 权重
3. **损失函数**：可增加 prior consistency loss
